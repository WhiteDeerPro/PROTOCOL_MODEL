# Protocol Model 0.4.0

0.4.0 固化从 `LinkProtocol` 命名与集中式 `protocol_model.link` 源码树迁出的第一版架构。逻辑接口内
可判定的合同现在由 `InterfaceProtocol`、`InterfaceSession` 和 `InterfaceConnection` 表达；规范中的真实
单向 hop、flit flow control 与 activation 继续由 transport 对象表达。该变化属于 pre-1.0 阶段的破坏性
API 迁移，不提供旧包兼容层。

## 本版闭合的路径

- `semantics`、`patterns` 与 observation 提供 scope-neutral event、资源/义务、ready-valid/reset 和异步四相
  握手 lowering；
- AXI4、AXI4-Lite、AXI4-Stream、AHB-Lite/AHB5、APB3/4/5 与受限 ACE-Lite 迁入
  `protocol_model.protocols` 协议族叶包；
- VirtualDut 以 module/port 边界组合 attachment、backend、address operation、translation、bridge、
  scheduled crossbar、queued/stepped emission、Sensor、DMA 与 interrupt recipe；
- SystemProtocol 以统一 topology registry 组合逻辑接口连接和定向 transport connection，并增加显式
  address contract/resolution、blocked step 原子回滚与只读分析边界；
- CHI Issue H 提供 typed message→packet→flit 表示、REQ/RSP/SNP/DAT transport、有限 router、direct read、
  Retry/P-Credit，以及受限 clean/dirty coherence participant 与 network session；
- 具名 Showcase 脚本保存可检查的 manifest、provenance、DOT/WaveJSON 源和渲染结果。

## 验证基线

默认 `make smoke` 使用 Python `unittest` 发现并执行 453 项测试。它们覆盖接口合法性、负例诊断、
VirtualDut operation effect、translation closure、有限资源与原子回滚、owner/ID correlation、CHI transport
与 coherence lifecycle、架构依赖方向和发布 artifact 边界。`tests/` 保存这些回归合同，不复制生产状态机。

## 当前边界

- `protocol_model.link` 已退役；调用方需要迁移到具体 `protocols` 叶包、`interface` 通用设施和
  `system.topology` 连接对象。
- CHI 仍是受限 Issue H slice：固定的 participant/profile、full-line DAT 和少量 opcode 不能概括完整
  RN/HN/SN、MESI/MOESI 或任意网络。
- address closure 当前要求显式 router contract 与 direct-neighbor claim；endpoint claim 自动派生、
  opaque boundary projection、multi-hop address resolution 和 bridge auto-lowering 尚未完成。
- runtime 已能表达有限容量、deferred emission 和 blocked rollback，但 held-resource wait-for、
  deadlock verdict、独立 egress admission、自主 wakeup 与多时钟时间窗口仍是后续工作。
- raw RTL/VCD/UVM adapter 与通用 reference/RTL refinement checker 尚未进入公共闭环。
